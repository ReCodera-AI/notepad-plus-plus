# ReCodera-AI Community Edition v2026.11.15.01

This is the first tagged release of the ReCodera-AI community edition. The release tag is independent of the upstream application's embedded version metadata.

> This project is developed and released independently by ReCodera-AI. It is not affiliated with, sponsored by, or endorsed by the original Notepad++ project or its maintainers.

## Changes From Pull Request #18596

This release packages the fork's bidirectional text and right-to-left editing work described in [PR #18596](https://github.com/notepad-plus-plus/notepad-plus-plus/pull/18596), which was closed without being merged upstream.

- Improved mixed Arabic and English layout in left-to-right documents, including text measurement, caret placement, selection, and background rendering.
- Added a GDI and Uniscribe rendering path for mirrored right-to-left views, preserving natural left-to-right order for English text.
- Added full-line DirectWrite layout drawing for coherent bidirectional shaping and wrapping.
- Corrected trailing line background gaps and dark strips.
- Improved caret, hit-testing, selection, and indicator alignment across mixed-direction text.
- Persisted text direction per document across buffer changes and session restoration.
- Switched rendering technology automatically when changing direction and restored the user's preferred renderer on return to left-to-right mode.

## Platforms And Packages

- Windows x64 (AMD64), x86 (Win32), and ARM64 MSVC builds are available, along with an x64 UCRT64 GCC build. Download them from the [GitHub release](https://github.com/ReCodera-AI/notepad-plus-plus/releases/tag/v2026.11.15.01).
- Linux packages are not available: the upstream Notepad++ project and this fork use a Windows-native build system.
