# ReCodera-AI Community Edition | Notepad++ v2026.11.22.02

This release introduces an automated self-healing bootstrap for User Defined Languages (UDL), ensuring pre-installed language definitions such as Markdown (`.md`) are automatically provisioned and syntax-highlighted on clean Windows installations. It bundles all 80+ programming language lexers, 96 UI localizations, 43 autocomplete libraries, and establishes the official Knowledge Base & FAQ Center.

## Key Changes & Enhancements

- **Self-Healing UDL Engine**: The C++ core (`Parameters.cpp`) now detects missing user profiles and automatically replicates default UDL XML definitions (including `markdown._preinstalled.udl.xml` and dark mode styling) into `%APPDATA%\Notepad++\userDefineLangs\` upon startup. Clean installations and post-cleanup environments will never lose Markdown syntax highlighting.
- **Admin Installer Language Bundling**: The NSIS administrative installers (`x64`, `x86`, `ARM64`) package all 80+ programming language models (`langs.model.xml`), 22 styling themes (`stylers.model.xml`), 96 localization languages, and automatically stage `userDefineLangs/` into both `Program Files` and the active user's `AppData`.
- **FAQ & Troubleshooting Knowledge Base**: Created the dedicated [Help & FAQ Portal](../faq/README.md) and the comprehensive [Markdown Syntax Highlighting Diagnostic & Resolution Guide](../faq/troubleshooting/markdown-syntax-highlighting-missing.md).
- **Independent Version Governance**: Retains `v2026.11.22.02` product version metadata and repository links across the About dialog, standalone binaries, and Windows installer packages.
