# ReCodera-AI Community Edition | Notepad++ v2026.11.22.02

The About dialog shows the independent release identifier and links directly to the ReCodera-AI GitHub repository. The Windows installers package the binaries built from this release.

## Windows Installers

Choose x64 for Intel or AMD 64-bit Windows, x86 for 32-bit Windows, or ARM64 for Windows on ARM. The installers add Notepad++ to the current user's Start menu and Windows Settings.

Close any running Notepad++ windows before launching the newly installed copy from its ReCodera-AI Start menu shortcut.
