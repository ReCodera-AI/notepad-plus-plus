# Notepad++ v8.9.8.2 — ReCodera-AI Community Build

This community build carries three focused fixes for document direction and text rendering. It is based on the Notepad++ source maintained by the original project at [notepad-plus-plus/notepad-plus-plus](https://github.com/notepad-plus-plus/notepad-plus-plus). It is an independent community release and is not an official upstream Notepad++ release.

## Fixed

### Arabic and English text in LTR documents

Corrected the visual placement and clipping of mixed bidirectional text while the document direction is left-to-right. Arabic runs retain their Unicode right-to-left reading order, while Latin text remains left-to-right. The Scintilla drawing path now uses DirectWrite visual intervals for text and background rendering, including whitespace and selections.

### RTL direction is restored for each file

Store the chosen direction with the document and restore it when reopening a file, switching buffers, and restoring a saved session. This keeps one file's RTL setting from being lost when the active tab changes.

### DirectWrite behavior when changing direction

Keep the configured DirectWrite renderer and bidirectional layout enabled for LTR documents. Use the compatible default rendering technology while RTL window mirroring is active, then restore the configured renderer when returning to LTR.
