# ReCodera-AI Community Edition v2026.11.22.01

This release incorporates 15 changes from [Notepad++ master through `c3cfef5`](https://github.com/notepad-plus-plus/notepad-plus-plus/compare/a3b459a...c3cfef5), following the upstream [Notepad++ 8.9.9.1 release](https://github.com/notepad-plus-plus/notepad-plus-plus/releases/tag/v8.9.9.1) already included in this fork.

- Fixes pinned-tab ordering, Document List selection, and file drag-and-drop between instances.
- Preserves the viewport while trimming spaces, fixes reverse navigation in search results, and refreshes the search caption when the UI language changes.
- Improves DPI handling for the document map and tree views, adds styling for C++ user-defined literals, and adjusts keyboard focus order in Find.
- Improves handling of missing XML values and long strings, and corrects Windows installer product-version metadata.

The fork retains its BiDi and RTL editing and session-persistence changes. See the [previous release notes](v2026.11.15.01.md) for their details.
